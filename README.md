# CSC2211 การออกแบบประสบการณ์และส่วนติดต่อผู้ใช้
### User Experience and User Interface Design · รหัสกลุ่ม 684242010 · ภาคเรียนที่ 2/2569

คลังเอกสารประกอบการสอนรายวิชา CSC2211 คณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏร้อยเอ็ด
ประกอบด้วยเอกสารประกอบการสอน สไลด์บรรยาย ใบความรู้ และใบงานตลอดภาคเรียน

> ผู้สอน: อาจารย์ ดร.เขมวิทย์ จิตตะยโศธร หลักสูตรวิทยาการมัลติมีเดียและปัญญาประดิษฐ์ คณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏร้อยเอ็ด

## เกี่ยวกับรายวิชา

รายวิชานี้พานักศึกษาผ่านกระบวนการออกแบบที่เริ่มจากผู้ใช้ ตั้งแต่การแยกปัญหาประสบการณ์ (UX) ออกจากรายละเอียดส่วนติดต่อ (UI) การวิจัยผู้ใช้ การสังเคราะห์ข้อมูล การนิยามปัญหา การออกแบบโครงสร้างสารสนเทศและเส้นทางผู้ใช้ การสร้าง wireframe และต้นแบบ ไปจนถึงการทดสอบการใช้งานและปรับแบบ โดยตลอดรายวิชาใช้หลักฐานจากผู้ใช้ จริยธรรม และการคุ้มครองข้อมูลส่วนบุคคลเป็นหลักในการตัดสินใจออกแบบ

**ผลลัพธ์ที่คาดหวังเมื่อจบรายวิชา** นักศึกษาสามารถวิจัยผู้ใช้ นิยามปัญหา ออกแบบและสร้างต้นแบบโต้ตอบ ทดสอบกับผู้ใช้ และนำเสนอกรณีศึกษา UX/UI พร้อมหลักฐานที่ผู้อื่นตรวจสอบย้อนกลับได้

## จริยธรรมและการคุ้มครองข้อมูล

- ทุกงานที่เกี่ยวกับผู้ใช้ต้อง **ขอความยินยอมก่อนบันทึก** และใช้ **รหัสแทนชื่อ** (เช่น P01)
- ตัดชื่อ รหัสนักศึกษา อีเมล และข้อมูลระบุตัวตนออกจากชิ้นงานที่แชร์
- ข้อมูลจำลองต้องระบุว่าเป็น "ข้อมูลจำลอง" ชัดเจน ห้ามนำเสนอเป็นผลจากผู้ใช้จริง
- ห้ามนำข้อมูลระบุตัวตนของผู้เข้าร่วมเข้าเครื่องมือ AI ภายนอก
- แนวปฏิบัติสอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 และนโยบายของมหาวิทยาลัย

### การใช้ Generative AI

ใช้ AI ช่วยระดมความคิด ตรวจภาษา และวิจารณ์ร่างงานได้ แต่ **ห้ามใช้สร้างหลักฐานแทนการทดลองใช้หรือการสัมภาษณ์จริง** ทุกงานต้องแนบ AI Log ระบุเครื่องมือที่ใช้และสิ่งที่ตรวจแก้เอง
